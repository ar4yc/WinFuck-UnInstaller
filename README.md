# WinFuck-UnInstaller

A TUI tool to reanimate your Windows system after using [WinFuck](https://github.com/ar4yc/WinFuck-CSharp), which can also be used to clean up after other malware.

## Disclaimer & Safety Warning

> **CRITICAL:** This utility modifies system-level configurations, registry hives, and core file paths. 
> * **Run as Administrator:** The application requires elevated administrator privileges to function correctly.
> * **Use at Your Own Risk:** The developers are not responsible for any data loss or system instability.

## Features

The uninstaller includes dedicated restoration modules to fix specific Windows damages:
1. **Restore Notification**
2. **Restore Filters**
3. **Restore Windows Updates**
4. **Restore Recovery**
5. **Restore Reset tools**
6. **Disable Block AV sites**
7. **Kill ResetSurvival**
> **Warning! This option can break built-in driver installers before system reset.**
